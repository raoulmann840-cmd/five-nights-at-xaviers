# Xavier — photo slot

Drop photos here (all optional — the game uses a vector animatronic if a file is missing):

| File name       | What it's for                                                         |
|-----------------|-----------------------------------------------------------------------|
| `normal.png`    | **Headshot.** Becomes the animatronic's face everywhere in the game.  |
| `jumpscare.png` | Full-screen scream photo (wide-open mouth works best).               |
| `hallway.png`   | Full-body photo shown standing in the hall / closet.                 |

`.png`, `.jpg`, `.jpeg` and `.webp` all work. Names must be lowercase and exact.
Photos are automatically darkened, desaturated, grained and vignetted to fit the horror look.
