# Zynovan Snusvac — asset slot

All files are optional. Anything missing uses the built-in 3D render.

| File | What it does |
|---|---|
| `face.png` | **Headshot.** Wrapped onto the animatronic's 3D skull before pre-rendering, so it is shaded, shadowed and lit by the flashlight together with the body. Best: front-facing, face centred, eyes ~40% from the top. |
| `locker_stage_1.png` … `locker_stage_4.png` | Sprite inside / climbing out of the supply locker |
| `gameover.png` | Portrait on the game-over screen after this villain catches you |
| `poster.png` | Framed poster on the classroom wall (Teacher of the Month / Hall Monitor / Supply Manager) |
| `jumpscare_stage_1.png` … `jumpscare_stage_12.png` | Your own jumpscare frames, played in order (1 = far, last = in your face). Stop numbering wherever you like. |

`.png`, `.jpg`, `.jpeg` and `.webp` all work. Names must be lowercase and exact.
Sprites get an automatic horror grade plus a generated normal map so the beam rakes across them.
