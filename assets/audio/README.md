# Audio — sound overrides

`scream.wav` is included (the jumpscare scream; played through a distortion stage at high gain).
Every other sound is synthesized live. To replace one, drop a file with this name
(`.wav`, `.mp3` or `.ogg`):

| Name | Used for |
|---|---|
| `scream` | Jumpscare |
| `breathing` | Steven at the hallway door (looped, 3D-positioned) |
| `whisper` | Xavier at the storage door (looped) and his whispers |
| `footstep` | One footstep (Steven in the hallway) |
| `locker_creak` / `locker_bang` | Supply-locker hinge creak / Zynovan banging |
| `giggle` | Little Xaviers on the desks |
| `ambience` | Background room tone (looped) |
| `bell` | 6 AM school bell |
